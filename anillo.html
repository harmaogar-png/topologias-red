Topología Anillo

Flujo de datos determinista mediante paso de testigo

¿Qué es exactamente?

La topología anillo conecta cada nodo con exactamente otros dos nodos, formando un círculo cerrado o bucle continuo. Los datos viajan en una sola dirección (unidireccional) o en ambas (bidireccional/dual ring).

A diferencia de Ethernet, aquí no hay colisiones. Se utiliza un mecanismo llamado "Paso de Testigo" (Token Passing): un paquete especial (token) circula por el anillo. Solo el nodo que posee el token tiene permiso para transmitir datos. Cuando termina, pasa el token al siguiente nodo. Esto garantiza un acceso ordenado y predecible al medio.

Ventajas y Desafíos Técnicos

Fue la base de tecnologías como Token Ring (IBM) y FDDI. Sus características son únicas:

  • Rendimiento Determinista: Como no hay colisiones, el tiempo máximo de espera para transmitir es conocido y fijo. Ideal para aplicaciones en tiempo real donde la latencia variable es inaceptable.
  • Equidad en el Acceso: Todos los nodos tienen la misma oportunidad de transmitir. Ningún dispositivo puede "monopolizar" el ancho de banda, a diferencia de CSMA/CD en Bus/Estrella.
  • Fragilidad ante Fallos: En un anillo simple, si un solo nodo se apaga o un cable se corta, todo el anillo se rompe y la red deja de funcionar. No hay camino alternativo.
  • Complejidad de Mantenimiento: Agregar o quitar un nodo requiere interrumpir temporalmente el anillo (a menos que se usen switches con bypass automático). El diagnóstico de fallas puede ser lento.

¿Dónde se usa hoy en día?

Aunque Token Ring desapareció de las oficinas, el concepto de anillo sobrevive en infraestructuras críticas:

  • FDDI (Fiber Distributed Data Interface): Anillos dobles de fibra óptica que conectan campus universitarios y backbones metropolitanos. Si el anillo primario falla, el secundario toma el control automáticamente.
  • SONET/SDH: La columna vertebral de las redes de telecomunicaciones globales usa anillos de fibra para transportar voz y datos con protección 1+1.
  • Automatización Industrial: Protocolos como PROFIBUS DP o DeviceNet usan topología anillo para conectar PLCs y sensores en líneas de producción.
  • Redes MAN (Metropolitan Area Networks): RPR (Resilient Packet Ring) para conectar edificios en una ciudad con alta disponibilidad.

Dato Técnico Avanzado

Para solucionar la fragilidad del anillo simple, existe la Topología de Anillo Dual. Usa dos anillos físicos que transportan datos en direcciones opuestas. El anillo secundario está normalmente inactivo ("standby"). Si el primario falla, los nodos detectan la ruptura y reconfiguran automáticamente el tráfico hacia el anillo secundario en milisegundos. Esta es la base de la resiliencia en redes SONET/SDH y FDDI.
